# kku-hackathon-project

A single-page CV / portfolio website: one `index.html` you can open directly
or publish with GitHub Pages, showing a photo, bio, skills, experience,
projects and contact links.

## What it does

- Shows a personal CV / portfolio on one scrollable page: header with name
  and photo, a short bio, a skills list, a work/education timeline, a
  projects grid, and a contact section.
- Loads built-in example content the moment it's opened (nothing to set up),
  plus a "Load example" button to reset back to it.
- Everything you type into any editable field is saved in the browser
  (`localStorage`) so it's still there next time you open the page on the
  same computer. Nothing you type is ever sent anywhere or committed to
  GitHub.
- Works fully offline: no server, no build step, no external fonts or
  images — just open the file.

## Who it is for

A student who wants a simple, ready-to-share personal CV / portfolio page
for job or internship applications, without needing to know web hosting or
design tools.

## Needs

- Any modern browser (Chrome, Edge, Firefox).
- No installs, no accounts, no API keys.
- (Optional, later) a profile photo — see `sample-data/README.txt` for how
  to add one; a placeholder is used until then.

## How to run it

1. Open `index.html` by double-clicking it (or right-click → Open with →
   your browser).
2. The page works immediately with example content already filled in.
3. Edit the fields on the page to replace the example content with your
   own — your changes save automatically in this browser.

## Try it with the sample data

Click the **Load example** button at any time to reset the page back to the
built-in made-up example CV, so you (or anyone reviewing this project) can
see every section filled in without typing anything.
