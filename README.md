# What it does

It takes professional portfolio content and gives a bilingual interactive portfolio page with a print-ready one-page CV.

# Who it is for

Students and early-career professionals who want to present their experience, skills, and projects in English and Arabic.

# Needs

Nothing but a modern web browser.

# How to run it

Start from a fresh download of this repository.

## Windows

1. Open the downloaded project folder.
2. Double-click `index.html`.

## Mac

1. Open the downloaded project folder.
2. Open `index.html` in a web browser.

# Try it with the sample data

Open `index.html`. The made-up portfolio data from `sample-data/data.js` loads automatically. You should see a bilingual portfolio page with profile, experience, skills, initiatives, a language switcher, a theme switcher, and a Print / Save PDF button.
